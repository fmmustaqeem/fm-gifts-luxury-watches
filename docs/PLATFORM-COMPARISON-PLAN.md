# FM Gifts & Luxury Watches — Daraz-style Plan

## Positioning
Separate retail storefront inspired by the Daraz marketplace model. This project remains independent from FM Market and FM B2B Market.

## Catalog
- Watches: Men, Women, Kids, Brands, Smart/Digital, Luxury
- Perfumes: Men, Women, Unisex, Brands
- Kids Watches: Baby, Boys, Girls, Digital, Cartoon
- Gifts & Accessories: Wallets, Belts, Cufflinks, Ties, Clocks, Gift Sets

## Customer side
Home, Shop, Categories, Subcategories, Brands, Product Detail, Search/Filters, New Arrivals, Offers, Featured, Cart, Checkout, Account, Orders.

## Private admin
Catalog, categories, brands, SKU/variants, inventory, pricing, orders, customers, marketing, advertising, SEO, content and site editing.

## Rules
- Separate deployment, domain, catalog and data.
- Supplier/reseller/wholesaler source data stays private unless explicitly configured.
- No production claim without CI/deployment evidence.
- One change -> one commit -> CI -> evidence.
